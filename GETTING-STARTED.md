# Getting started with Overlane

Overlane runs **on your PC**. Nothing is uploaded off your machine by default.

## 1. Install

1. Open **[short.army/overlane](https://short.army/overlane)** and download the latest **Overlane** Windows installer (or **Overlane Demo** to try without the game).
2. Run the installer and start **Overlane** from the Start menu.

## 2. Connect the game (live telemetry)

1. On first launch, follow the **game link** wizard: pick your ETS2 or ATS install folder.
2. Install the **official Overlane telemetry plugin** when prompted (or choose another supported plugin you already use).
3. Launch the game and load a profile — the console health strip should show telemetry when the plugin is active.

## 3. Use overlays

1. Open **Overlays** in the console.
2. Copy a panel URL into OBS (Browser Source) or open it in a browser tab beside the game.
3. Adjust appearance under **Settings** if needed.

## 4. Optional: record your drives

Enable recording under **Settings → Storage** when you want timelines, search, and dashboards from saved snapshots.
