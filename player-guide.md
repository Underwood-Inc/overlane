# Overlane — player guide

Overlane is a **telemetry console** for Euro Truck Simulator 2 and American Truck Simulator: live overlays, a driving archive, session journal, and an optional Windows desktop app.

## What you need

1. **A supported telemetry plugin** in the game’s plugins folder (the desktop wizard can install the official Overlane plugin).
2. **Overlane** — the Windows desktop app from [short.army/overlane](https://short.army/overlane), or a local install your team provides.

## Quick start

1. Start the game and load a profile.
2. Open the **Overlane** console — the health strip should show telemetry when the plugin is connected.
3. **Overlays** — copy a panel URL into your streaming or overlay app.
4. **Archive** — enable recording under **Settings → Storage** to build a searchable timeline of your drives.

## Desktop app (Windows)

- Installs to your user profile under **Overlane** (typical path: `%LOCALAPPDATA%\Overlane\`).
- **Tray menu**: open the console or quit (quit before running an installer upgrade).
- Optional **Start when I sign in** under **Settings → Connection**.

## Demo installer

**Overlane Demo** includes sample telemetry so you can explore the console, archive, and overlays **without** the game. It is ideal for stream setup and UI tours.

## Privacy

Data stays on your machine unless **you** export it or change server bind settings. The desktop app listens on **localhost** by default.
